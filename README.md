# Crowd Monitoring System (CMS)

This project is a Crowd Monitoring System that analyzes video footage to estimate crowd density and visualize crowd movement patterns using computer vision and deep learning techniques.

---

## 🔧 Requirements

- Python 3.9 / 3.10
- Virtual Environment (recommended)
- Dependencies listed in `requirements.txt`

---
